AI & Machine Learning ML.01
Implementasi Chatbot dengan Metode IndoBERT untuk Prediksi Kode KBLI 5 Digit pada UMKM Berbasis Website

Chatbot berbasis IndoBERT yang membantu pelaku UMKM menentukan kode KBLI 5 digit dengan lebih mudah dan cepat. Dataset dikumpulkan melalui web scraping, kemudian dilatih menggunakan model klasifikasi IndoBERT di Google Colab. Untuk mengatasi ketidakseimbangan data pada proses pelatihan, diterapkan teknik augmentasi data dan random undersampling, menghasilkan akurasi model sebesar 95% pada top-3 accuracy. Model kemudian diintegrasikan dengan Flask untuk membangun antarmuka chatbot, serta Gemini API agar respons yang dihasilkan lebih natural dan mudah dipahami pengguna.

Machine Learning ML.02
Sentiment Analysis — Palestine Twitter

Project data mining untuk analisis sentimen masyarakat pada aplikasi X terhadap genosida yang terjadi di Palestina, menggunakan metode Naive Bayes. Karena ditemukan ketidakseimbangan data pada dataset, diterapkan teknik SMOTE (Synthetic Minority Oversampling Technique) untuk menyeimbangkan kelas data, sehingga akurasi model meningkat dari 95% (Naive Bayes saja) menjadi 98% setelah penerapan SMOTE.
