AI & Machine Learning ML.01
Website-Based Chatbot Using IndoBERT for 5-Digit KBLI Code Prediction for SMEs

An IndoBERT-based chatbot that helps small business owners (UMKM) determine their 5-digit KBLI business classification code more easily and quickly. The dataset was collected through web scraping, then used to train an IndoBERT classification model on Google Colab. To address data imbalance during training, data augmentation and random undersampling techniques were applied, achieving 95% top-3 accuracy. The model was then integrated with Flask to build the chatbot interface, along with the Gemini API to make responses more natural and easier for users to understand.
